# Undertow (was The Lure) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship "Undertow" — a melancholy gothic mermaid dress-up web game: she was human, cursed into the sea to protect her; the man searching for her reacts live across the water while she dresses for the beach party; 3 tragic endings + 1 secret good ending ("Found") — as an itch.io HTML5 build within a 24-hour jam. Characters are unnamed by design.

**Architecture:** One static page: a fixed-aspect stage of stacked absolutely-positioned `<img>` layers driven by a data file (array order = z-order), a pure scoring module (the only node-tested code), a watcher (Kai) reaction state machine, and a 5-state game flow (TITLE → TAIL_SELECT → DRESSING → ASHORE → ENDING). Art arrives in batches; everything boots on placeholder PNGs first.

**Tech Stack:** Vanilla HTML/CSS/JS (ES modules), `node --test` for pure logic, Python/PIL + rembg for asset slicing, itch.io HTML5 deploy. No frameworks, no build step.

**Spec:** `/Users/yanai/Desktop/halloween-jam/game-design.md` (+ `reference-board.md` for rationale)

## Global Constraints

- Stage master canvas: **1200×1800** portrait; every wearable layer is a full-canvas PNG at (0,0) — no anchor math.
- Layer z-order (bottom→top): `bg, hair_back, base, top, neck, hair_front, head, held, fx`.
- Vibes: exactly `"tide" | "masque" | "memory"`; tail biases: oceanic→memory, pearlescent→masque, deep_current→tide, reef→wild (rolled **once per run**).
- Tie-break (spec §Vibe System): bias vibe wins if among tied; else the **most recently equipped** item's vibe among the tied wins.
- Ending resolution (spec §Endings): tide→`sea_rises`, masque→`perfect_night`, memory→`almost` unless a `hero:true` item (the locket) is equipped, then `found` (the secret).
- Click-to-equip only; equipping an occupied slot replaces; clicking an equipped thumb unequips.
- No text modals during dressing; max 1–2 text lines per ending.
- Never cut (spec cut-list): the 4 endings, equip feel, the Walk Ashore reveal, the locket gate.
- itch.io zip: `index.html` at root, case-sensitive paths, GenAI disclosure = yes.
- All game files live in `/Users/yanai/Desktop/halloween-jam/game/`; tools in `tools/`; this repo gets `git init` in Task 1.

## Review Focus

1. **Walk ashore with nothing equipped** → tail bias alone decides (Reef = its rolled vibe; oceanic naked = `almost`); must not crash or soft-lock. → test in Task 2.
2. **Tie where the bias vibe is NOT among the tied** (e.g. tide 2 / masque 2, bias memory) → last-equipped among tied wins. → test in Task 2.
3. **Unequip then re-tally** → removed item's vibe must leave the counts and the watcher's tier must update; unequipping the locket must close the secret gate. → test in Task 2 + browser check in Task 5.
4. **Replay (R on ending)** → full state reset: equips cleared, Reef re-rolled, watcher tier reset, music/grade reset. → test in Task 4 step 6.
5. **Slow/failed image loads** → preload gate with `img.decode()`; a missing file must log and show the stage without the layer, never a broken-image icon mid-play. → verified in Task 3 step 5.

### Task 2: Vibe scoring module (the tested core)

**Files:**
- Create: `game/js/vibes.js`, `tests/vibes.test.mjs`

**Interfaces:**
- Produces: `resolveBias(tailId, rand=Math.random) -> "tide"|"masque"|"memory"` (reef uses `rand` once; others fixed per Global Constraints). `tally(equippedVibes, biasVibe) -> {counts:{tide,masque,memory}, dominant}` where `equippedVibes` is an array of vibe strings **in equip order** (cosmetic/null vibes already filtered by caller). `resolveEnding(dominant, hasHero) -> "sea_rises"|"perfect_night"|"almost"|"found"`.

- [ ] **Step 1:** Write failing tests in `tests/vibes.test.mjs` (`node:test`):

```js
assert.equal(tally([], "memory").dominant, "memory");                         // naked walk-ashore
assert.equal(tally(["tide","tide","masque"], "memory").dominant, "tide");     // plain majority
assert.equal(tally(["tide","masque"], "masque").dominant, "masque");          // bias breaks tie it belongs to
assert.equal(tally(["tide","masque"], "memory").dominant, "masque");          // bias not among tied → last-equipped
assert.equal(tally(["masque","tide"], "memory").dominant, "tide");            // order matters
assert.deepEqual(tally(["tide"], "tide").counts, {tide:2, masque:0, memory:0}); // bias counts as +1
assert.equal(resolveBias("deep_current"), "tide");
assert.equal(resolveBias("reef", () => 0.1), "tide");                         // deterministic under injected rand
assert.equal(resolveEnding("tide", false), "sea_rises");
assert.equal(resolveEnding("masque", true), "perfect_night");                 // hero item irrelevant off-branch
assert.equal(resolveEnding("memory", false), "almost");                       // the cruelest ending
assert.equal(resolveEnding("memory", true), "found");                         // the secret
```
